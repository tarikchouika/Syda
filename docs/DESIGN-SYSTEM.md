> مصدر الحقيقة الوحيد لتصميم متجر صيدة. مستوحى من Amazon (الهيدر والكثافة)، Jumia (شارات الخصم وشريط التطبيق)، Seeda (الزوايا الحديثة وتفاعلات الهوفر).

## 🧩 المكونات الأساسية

### الهيدر (يُولَّد من `renderHeader()` في site-ui.js)
- `topstrip`: شريط ذهبي علوي (توصيل + دفع عند الاستلام) — يختفي ≤640px
- `sitebar`: شعار ← بحث كبسولة (أبيض + زر ذهبي 🔍) ← إجراءات (سلة بعدّاد أحمر، لغة، ثيم، قائمة)
- `#catbarNav` (خارج الهيدر اللاصق): شارات فئات قابلة للتمرير، النشطة بخلفية خضراء

### بطاقة المنتج
```
.card (أبيض، radius-lg، ظل-1، هوفر: رفع -5px + ظل-2)
├── .card-media
│   ├── .card-img (نسبة 1:1، object-fit:contain، هوفر: تكبير 1.07)
│   │   └── .save-chip (شارة خصم حمراء −٪)
│   └── .add.quick-add (زر دائري أخضر + أيقونة سلة، يظهر عند الهوفر)
└── .body
    ├── .card-cat (شارة القسم)
    ├── h3 (سطران كحد أقصى)
    ├── .price + .old-price (مشطوب) + .save-badge
    └── .card-actions (.btn ذهبي "عرض التفاصيل" + .add أخضر "أضف للسلة")
```

### صفحة المنتج
- `.product`: شبكة عمودين (معرض 55% / معلومات 45%)
- `.buybox`: صندوق شراء ثابت (السعر كبير + الخصم + أسعار الكميات + الشحن + زر ذهبي كبير)
- `.mobile-buybar` (≤860px): شريط شراء سفلي ثابت: السعر + زر الإضافة

### الهومبيج
هيرو (تدرج + فقاعات ذهبية + زران CTA + شارات ثقة) ← بلاطات الفئات (12 بأيقونات) ← أدوات التصفية ← شبكة المنتجات ← شريط التطبيق (mockup هاتف + QR + زر تحميل) ← شريط الميزات (4) ← الفوتر

### الفوتر (يُولَّد من `footerText()`)
4 أعمدة: العلامة والوصف | الفئات | روابط سريعة | تحميل التطبيق (QR + زر + رابط دائم)

## 📏 قواعد إلزامية

1. زوايا البطاقات: `--radius-lg` — الأزرار: 12px — الكبسولات: 999px
2. الهوفر: رفع -4/-5px + ظل أعمق + مدة 0.2s (احترام `prefers-reduced-motion`)
3. كل عنصر تفاعلي له حالة `:focus-visible` (إطار ذهبي)
4. أي صورة داخل بطاقات: `loading="lazy"` + `onerror` → الشعار
5. النصوص الثابتة الجديدة: سمات `data-ar` / `data-en` (يُبدّلها `applyStaticI18n`)
6. الوضع الداكن: عبر متغيرات `body.dark` — لا ألوان صريحة داخل المكونات
7. داخل تطبيق الأندرويد (`body.in-app`): تُخفى كل عناصر تحميل التطبيق
