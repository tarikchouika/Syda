# دليل تطبيق صيدة للأندرويد — App Guide

> ملف المعرفة المرجعي لتطبيق الأندرويد: البنية، التوقيع الدائم، البناء الآلي، والنشر.

## 📱 نظرة عامة

تطبيق **صيدة** هو غلاف Capacitor احترافي حول المتجر المباشر `https://syda.pages.dev`:

| الخاصية | التنفيذ |
|---------|---------|
| المعرف | `com.syda.store` |
| الاسم | صيدة - Syda |
| المحتوى | يعكس الموقع المباشر دائماً (لا نسخ قديمة، لا ملفات ثقيلة) |
| ملء الشاشة | وضع شامل غامر (Immersive Sticky) يخفي شريطي النظام العلوي والسفلي عبر `MainActivity.hideSystemBars()` — الواجهة الحديثة (WindowInsetsController) لأندرويد 11+ والواجهة القديمة للإصدارات الأدنى |
| الشاشة | `viewport-fit=cover` + `shortEdges` لدعم النوتش — ينسجم مع أبعاد الهاتف 100% |
| الأيقونة | اللوغو الرسمي على خلفية `#06452f` (أيقونة متكيفة Adaptive Icon) |
| شاشة البدء | أخضر عميق + اللوغو (كل الكثافات) ثم تلاشٍ ناعم |

**لماذا `server.url` وليس ملفات محلية؟** لأن الطلبات تمر عبر Pages Function الخاصة بالمتجر والسلة تعمل بالكامل، والتطبيق يتحدث تلقائياً مع كل تحديث للموقع — بدون إصدار جديد للتطبيق.

## ⚙️ البناء الآلي (GitHub Actions)

`.github/workflows/android.yml` يعمل عند كل دفع لـ `main` (تغييرات `site/` أو `app/`) أو يدوياً:

1. تهيئة Node 20 + Java 17 + Android SDK
2. `npm ci` + `npx cap sync android`
3. `versionCode` = رقم التشغيل (يتزايد تلقائياً)
4. فك ترميز المفتاح من Secrets
5. `gradlew assembleRelease` بتوقيع محقون (لا أسرار في الملفات)
6. التحقق من التوقيع بـ `apksigner` واستخراج بصمة الشهادة
7. حذف إصدار `latest-app` القديم وإنشاء الجديد (مُعلَّم كـ `--latest`)

|--------|-------|
| `https://github.com/tarikchouika/Syda/releases/latest/download/syda-store.apk` | **تحميل آخر إصدار دائماً** — مدمج في الموقع |
| `https://github.com/tarikchouika/Syda/releases/latest` | صفحة آخر إصدار (سجل التغييرات) |
| `https://syda.pages.dev/app` | صفحة التثبيت + دليل Play Protect داخل المتجر |

## 🛠️ بناء محلي (للتطوير)

```bash
cd app
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## 📲 تثبيت المستخدم النهائي

1. تحميل `syda-store.apk` من الرابط الدائم أو مسح QR من `/app`
2. السماح بالتثبيت من المصدر (المتصفح/مدير الملفات)
3. عند تحذير Play Protect: **تفاصيل ← تثبيت على أي حال** (روتيني لكل تطبيق خارج متجر Play)
4. التحقق الأمني (اختياري): مطابقة بصمة SHA-256 للشهادة أعلاه عبر `apksigner verify --print-certs`

## 🔄 تحديث التطبيق

المحتوى يتحدث تلقائياً (يعكس الموقع). إصدار APK جديد يلزم فقط عند: تغيير الأيقونة/الاسم/المعرّف أو إضافة ميزات أصلية (إشعارات مثلًا) — ادفع لـ `main` وسير العمل يتكفل بالباقي تلقائياً.
